**AI reading answers faster.** A new switch in Settings, **Let the model think**, is off by default: the model is asked to answer at once, which is much faster, and reading pages rarely needs more. There is no common way to ask for that, so Tessel asks in every way servers know (OpenAI, DeepSeek, Qwen, GLM, Kimi, vLLM, Anthropic); a server that doesn’t know one says so, and Tessel asks again without it and remembers. Switched on, the model thinks as it would by itself.

Also: a model that can’t follow Tessel’s answer format is remembered on the device, so its first request after opening the app isn’t wasted.
