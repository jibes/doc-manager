**Tessel for macOS.** `tessel-3.6.0-mac.dmg` on this page (Apple silicon and Intel): Tessel in its own window, with everything the website does, and what a browser tab can’t:

- **AI reading with any model.** The app makes the requests itself, so a model’s address that doesn’t allow browser pages (most OpenAI-compatible servers) works.
- **Open with Tessel** from the Finder, or drop a PDF on its Dock icon.
- **The Tessel folder stays open.** The folder you chose (synced with Syncthing, say) is there again after a restart, without “let Tessel in again”.
- The scanner uses the Mac’s camera (asked once).

It isn’t signed with an Apple Developer ID: the first time, right-click Tessel in Applications → **Open** → **Open** (or System Settings → Privacy & Security → **Open Anyway**). After that it starts like any app.

Also: the app’s name and description say what it is now (a document manager for PDFs), and “Open with” no longer offers EPUB books.
