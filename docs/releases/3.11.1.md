**A second check of the whole app: fixes everywhere, and text in every script.**

- **The trash never touches files outside it.** When the trash folder was missing or couldn't be read, Restore and Delete for good acted on the Tessel folder itself — a file there with a trashed one's name could be deleted.
- **Text read from scans keeps every script.** Chinese, Hebrew, Arabic, Thai, symbols and emoji are now kept in the PDF's hidden text (they came back empty before, so they couldn't be searched or copied). The font for it is made for each file from the characters it has: a few kilobytes.
- **Selecting with the mouse:** clicking the page finishes a field or search being typed in again; a quick drag keeps its end; Ctrl-click on a Mac keeps the selection for the menu; dragging to the edge scrolls the pages.
- **Saving:** leaving a document or switching to another one beside the list offers Save; typed but unsaved details are mentioned; an undo during a save no longer marks the document as saved; reading text in the background waits while you type.
- **Documents:** narrowing the window keeps typed details; a deleted document closes beside the list; after a delete the cursor goes to the next row; Enter opens one document, not two; Escape closes menus and the details of several documents, ↑ ↓ go through menus; filled-in copies of one form are no longer offered as older versions of each other.
- **Text view:** two-column scans read as text; a typed cover with scanned pages offers to recognise the scans; closing a document during recognition no longer leaves pages empty; invoice rows are read across again; bullet lists stay lists.
- **AI reading:** replies with a model's thinking or a note after the answer are understood; the key is no longer cleared while the address is typed; local addresses such as http://nas:11434 work everywhere.
- **Reliability:** a broken download of the PDF engine or the search worker gives an error instead of waiting forever; a file arriving in the inbox while it was being filed stays there.
- **Mac app:** files that can't be read no longer stop it; files opened with a relative path from a second start open; no PDF is opened twice. Menu wording matches the app.
