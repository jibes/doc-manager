**A debug log, precise mouse selection, and "last opened" shared between devices.**

- **Settings → Debug log → Log everything** keeps a record of what Tessel does on this device: screens opened, documents opened, read and saved, the folder's files, background reading, requests to the AI model (address, size, answer and time), settings changed, and every error. Off, only warnings and errors are kept.
- **Export log** saves it as a text file to send along with a problem; **Clear log** empties it. It never holds document text, notes' or fields' contents, or keys, and stays at most 4 MB: the oldest entries go first.
- **Selecting several lines with the mouse ends where the pointer is.** Dragging past the end of a line, between lines or into the gap between columns no longer jumps the selection lines further down (or back up); it ends at the nearest word. Double and triple clicks select a word and a line as before.
- **When a document was last opened and where it was left stay with it after it is saved** (or its text read again, or its pages cleaned up), which writes the file anew.
- **"Last opened" is the same on every device.** Each device notes when it opened a document in a small file of its own in the Tessel folder (`.tessel/opened/`), which Syncthing carries to the others; every device sorts by the latest. Where a document was left stays on each device (a phone's page isn't a desktop's).
