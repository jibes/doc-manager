**Details for every PDF.** ⋯ → Details gives a PDF a title, sender, type, date and tags. They are saved in the PDF itself, so other apps see them, and so do your other devices when the folder is synced (Syncthing, a cloud folder). Saving only adds a few hundred bytes to the end of the file and leaves the rest as it was. Scans read with AI get them too.

**AI addresses.** An Anthropic address now works with or without /v1 at the end.
