**Settings edited on two devices at once are merged, not lost.**

- When two devices changed the same settings before Syncthing synced them, Syncthing keeps one version and saves the other as a conflict copy (`….sync-conflict-….json`), which Tessel used to ignore. Now it merges the copy in: what the newer file has stays, and what only the copy has is added. The merged file is written back and the copy removed.
- This covers saved views (`.tessel/views.json`), inbox rules and the name template (`rules.json`), and types and tags (`kinds.json`).
- One limit: something deleted on one device while the other still had it comes back once and has to be deleted again.
