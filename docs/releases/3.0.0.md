**Tessel is a document manager now.** For PDFs only: one screen, one way in, no folders. Viewing books and browsing the whole device are left to apps made for that.

**One screen.** Documents is the app. No tabs, no sidebar, no Reading screen: the documents you opened last come first. **+** adds from the camera or from files. A line says when the inbox has documents to review; the trash, sync issues, duplicates and rules are under ⋯.

**One way in.** Whatever you add, scanned or picked, becomes a file in the Tessel folder (its Inbox once you sync a folder), and pages without text get theirs read on your device, so everything can be searched. With AI reading set up, the model can read the text instead: on by default in Settings, or switched on each add. Scans go there too; there is no folder to choose.

**Tessel | Sources.** Folders you add in Settings are sources: their PDFs sit on the Sources side, searched as well, and can be opened, kept in Tessel, shared or deleted. A search on one side says how many matches the other side has. All files access and the Folders view are gone.

**No folders in Tessel.** Tags, filters and saved views find documents; the Tessel folder holds only files, `Inbox/` and `.tessel/`. The name template names files only (default `{date} {sender} {title}`; a “/” is refused, and an old template's are read as spaces). Settings → Flatten moves the PDFs in old folders up, once: nothing is overwritten (a name already there gets “(2)”), and folders with other files in them stay.

**Duplicates.** ⋯ → Duplicates lists identical files (the copy in the Tessel folder stays, else the oldest) and older versions of a document (the newest stays), each with the space removing the others frees.

**The file is the truth.** Details, text, forms, highlights and notes live in the PDF. Bookmarks became notes on their pages; a note on a page is the note button or B. Where you left a document, its view and Invert are remembered on this device only. Reading lists and sharing reading state between devices are gone.

**In the browser too.** Without a folder picked, the browser keeps its own Tessel folder, and documents are real files in it (Safari and Firefox included).

**PDF only.** EPUB books no longer open. If you had some, Settings offers to save them and then remove them.

Also: a document opened from Documents opens where you left it again (a search hit still opens at its match).
