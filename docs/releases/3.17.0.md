**Types and tags: two separate questions, a fixed list of types in Settings.**

- **Type** is now what a document *is* (its form), exactly one per document. **Tags** are what it is *about* (a topic or area of life), one to three. A health insurance invoice: type Invoice; tags Health, Insurance; the insurer is the sender.
- **Settings → AI → Types and tags** (new): the list of types, each with a description of where its line runs. 15 defaults (Invoice, Receipt, Contract, Policy, Statement, Payslip, Notice, Reminder, Quote, Confirmation, Medical, Certificate, Manual, Letter, Other). Add, rename, describe or remove them; "Default types" brings the defaults back.
  - Kept in the Tessel folder (`.tessel/kinds.json`), so every device uses the same list. Without a Tessel folder: on this device.
- **AI suggestions** (details, reading added documents, Analyse) choose the type only from this list, guided by the descriptions; one that fits none gets the last type ("Other"). A tag that repeats a type or the sender is dropped.
- **Tags** can be listed there too, with descriptions: the model prefers them. With **Only these tags** switched on, it gives no others.
- **Tidy up → Types** starts from the list in Settings (all ticked). Existing types are sorted into it, by name or by content. With "Only these tags", the same holds for tags.
