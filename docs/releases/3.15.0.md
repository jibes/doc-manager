**Selected documents: Analyse and Tidy up, and a bar that fits any screen.**

When documents are selected in the list:
- **Analyse** reads pages without text (on the device, or by the AI model where one is set up) and, with AI, fills in empty details. Details a document already has stay.
- **Tidy up** opens Tidy up tags for just the selected documents. Disabled when none of them has a type or tags.
- Actions that don't fit the screen's width go behind ⋯. Share, Details, Analyse and Delete always stay visible.
