**PDF previews in the file picker** (Android app). Every app’s file picker (attachments, uploads, “open file”) now lists **Tessel** beside Downloads and the drives: the Tessel folder, with the first page of each PDF as its picture, which Android doesn’t draw for PDFs itself. Settings → File picker → **Show all files, with previews** adds **Internal storage** there too: every folder and file, with pictures of PDFs and photos (it asks for All files access). Both are read-only: picking hands out the file itself, nothing is copied or changed.

**+ opens files too.** Open file left the header: + → **Only look at a file** opens a PDF without keeping it, beside Camera and Files.

**Picking stays in view.** While documents are picked, the bar with the count and ✕ stays at the top as the list scrolls.
