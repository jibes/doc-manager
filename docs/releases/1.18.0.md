**Documents get to the point.** The Inbox and sync issues are small chips under the search field, and the filters fold into one Filter button that counts the active ones; active filters stay visible as chips. Filters without values are left out. With nothing to show yet, Documents says so once and offers Add folder.

**Inbox: see what you file.** Each document in the Inbox shows its first page; tap it to open the document. Rules and the file name template have their own screen (Rules, in the Inbox's header).

**Reading always has something to continue.** With nothing on the reading list, the document you opened last waits at the top, with Add to reading list beside it.

**Less in the way.** Select sits beside Sort in every list. On a phone, the page number and bookmark step aside while you scroll. The reader's ⋯ menu starts with Reading list and Share. Settings has jump links at the top, and the archive is a mark on one of your folders instead of a second list. All document screens are the same width.

**Better titles.** Placeholder titles that programs leave in PDFs ("Microsoft Word – …", "Document", "scan0001.pdf") give way to the file name, and in text view a large heading set on two lines stays one heading.

**AI reading in the Android app finds more addresses.** When the phone's DNS doesn't know an address (a newly made workers.dev name, or one a Private DNS filter drops), Tessel asks Cloudflare's DNS instead. If it still can't, the message says what to check.
