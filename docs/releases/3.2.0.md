**One Tessel folder, and nothing else.** Tessel reads and lists the documents in one folder only: this device's own (Documents/Tessel in the Android app, the browser's storage) or a folder you choose in Settings, usually one you sync. Sources are gone: folders added as sources are let go of once, and their files stay where they are.

**Choose the folder in Settings.** Choose a folder, or go back to this device's own. If the Tessel folder has documents, Tessel asks whether they move along (the inbox's to the new inbox) or stay where they are. Where you left each document is kept either way.

**Import a folder.** Settings → Import a folder copies every PDF in a folder, and in the folders inside it, into the Tessel folder once, as anything you add. Pages without text get theirs read. The folder itself is left as it was.

**Kept means copied in.** A file you open from elsewhere and keep, or save a form or note into, becomes a copy in the Tessel folder. The original is left alone; before, Chrome and Edge kept a link to it instead.

**Fewer dots.** ⋯ shows only when there are two or more things in it. A single one gets its own button.
