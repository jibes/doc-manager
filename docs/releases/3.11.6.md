**A fourth check of the whole app: the Tessel folder, scanning again, AI replies and the reader.**

- **Choosing the Tessel folder again** (the picker opens there) no longer renames every document to "… (2).pdf": it says it is the Tessel folder already. A folder inside or around it is refused, for importing too.
- **Changing the Tessel folder** takes the trash, the inbox rules and the saved views along; the new folder is checked before anything moves.
- **Adding a file that can't be opened** (damaged, a book, its password not given) no longer leaves a copy in the Tessel folder. When the folder can't be written, Tessel says the document stays on this device only.
- **Scan again** asks about an open scan restored after a reload, instead of mixing its pages into the document; stopped part way, it no longer replaces the document with some of its pages.
- **AI:** a reply after the model's thinking is read correctly (not the example from the question); redirects aren't followed, so the key and pages never go elsewhere.
- **Reader:** page keys stay out of a note being typed (a highlight's note no longer became a page note); opening Find or Aa over typed details asks first; pages turned a quarter select and copy as lines again; search marks at high zoom take far less memory; a document now shorter opens at its last page.
- **Smaller things:** a locked Tessel folder offers the other choices when access is refused; the trash empties on time without being opened; ← → no longer switch the page being cropped; ⌘K keeps the chosen row in sight; inbox entries and the name template are kept; a rule needs something to fill in; toasts go after five seconds, however busy the screen; "1 Seite ist" in German.
- **Android:** saving no longer writes a file back where it was moved from.
