**Selecting text in scans is precise again; undo, a Save choice, and faster big archives.**

- **Selecting and highlighting text in scanned pages follows the words again.** The hidden text was written a line at a time in a font of other widths, so selections drifted from the cursor and ran across columns. It is now written word by word, in a tiny font embedded once per file (a few kilobytes, not a font per word as before 3.9.1). Documents read in 3.9.1–3.10.0 get this when their text is read again (Improve text with AI, or Make searchable).

- **Leaving a document with unsaved changes offers Save** as the first choice, next to leaving without saving.
- **Removing duplicates can be undone** from the notice, and each copy shows its file name, so you can tell which one stays.
- **Files there twice are only under Duplicates**, no longer also counted as a sync issue; Sync issues are Syncthing's conflict copies.
- **Safari: a file is written whole or not at all** — closing the tab mid-save leaves the previous version, not a cut-off PDF.
- **Big archives:** thumbnails, the search index and removing documents no longer slow down with the number of files; very large PDFs (over 150 MB) are listed by name and details without being read; moving and renaming in the Tessel folder moves the file instead of copying it.
- **Android:** names with slashes or "..", links to other kinds of addresses, and lookups of local names (router.lan, nas.local) are handled more strictly.
