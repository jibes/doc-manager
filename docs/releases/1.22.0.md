**Improve text with AI.** With AI reading set up, ⋯ → Improve text with AI reads a document's text again: each page goes to your model as an image, with the text found on it (an earlier recognition's, or this device's where a page has none). The corrected text and what the model finds besides, such as handwriting, replace the invisible text, so search, selection and copying use it. Pages with typed text of their own stay as they are. Tessel asks first and says where the pages go.

**All documents: rename, move and delete.** With all files access, documents listed under All documents (in Download, say) can now be renamed, moved and deleted like those in your folders. Only making folders and pasting need a folder.
