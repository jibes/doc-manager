**Failures in share, download and print are now shown and logged, and the list reads fewer files.**

- Share, download and print no longer fail silently. When one fails, the reader says so, and the debug log keeps the reason. Every print is logged too: where it ran, and how many pages went to the print dialog.
- Moving the pointer across the list no longer reads every document it passes over. A document's file is read ahead for dragging out only once the pointer rests on its row for a moment, or presses it.
