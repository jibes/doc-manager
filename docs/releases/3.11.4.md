**Highlights you can click, forms you can read, and a third check of the whole app.**

- **A click on a highlight** offers its other colours, a note and Delete, right there. Undo while it is open closes it; a double click still selects the word; plain text beside a highlight over several lines opens nothing.
- **Text view shows what a form was filled in with:** "Full name: …", "◉ Large", "☑ I agree…" — and follows undo and redo.
- **Saving never brings back a file that has gone** (moved, put in the trash, filed on another device): it says so instead. In the browser, a new file where a deleted one was is no longer taken for it.
- **Selecting:** a drag that starts beside the text (the margin, a gutter) starts at the nearest word. Hebrew, Arabic and emoji are read as words again (they came in letter by letter).
- **Inbox:** its name opens a document too; removing one can be undone; the count shows as soon as this device sorts the inbox.
- **Smaller things:** menus at the pointer stay on screen beside the list; ↑ ↓ in the list take the keyboard along; ⌘K and Quick Look give the focus back; the details of several documents ask before typed changes are lost; removing a rule asks first; a toast without a button no longer blocks what is under it; German says "Angaben" throughout.
- **Under the hood:** the PDF engine reports a failure instead of waiting for ever; large text layers get as many fonts as they need; the Mac app of a release is built from that release; the debug log keeps no document keys or file contents.
