**Smaller fixes from a look at every screen.**

- **“Last opened” survives a new Tessel folder.** Documents added or kept on this device stay in the order you opened them after moving the Tessel folder; a document kept from the viewer keeps where you left it.
- **No stale rows after a new Tessel folder.** Right after choosing another folder, documents of this device’s own folder could stay listed for a few seconds, and tapping one said the file couldn’t be read as a PDF. Only the Tessel folder is listed now; a file gone from where it was says it is missing.
- **Rows say less.** With one folder, rows no longer repeat “Tessel folder” on every line; only documents still waiting in the inbox say so.
- **Reader.** A message (“Kept in Tessel.”) no longer covers an open sheet. While a document is being read as it was added, ⋯ doesn’t offer to read it again. The page note button has a note icon.
- **Wording.** “1 added document is searchable now.”, “Tessel folder changed. 2 documents moved.”, and the AI note in Settings mentions added documents too.
- Settings shows the version. On narrow phones the footer line no longer sits under **+**.
