**The scanner says clearly when the photo is taken, shows the page sharper and zooms in. The Mac app prints.**

Scanner
- The outline's colour means one thing at a time. Blue means it is looking for the page. Amber means keep still: it is counting down, or taking the photo. Green means taken, you can move. Green comes only once the photo exists, with a check mark, "Got it — you can move" and a buzz. While the same page stays in view, the outline stays green and says "Next page".
- The live picture runs faster. Where the phone takes its photos at full sensor size (Android), the preview no longer streams the full sensor too: it streams about 1920 px at up to 30 frames a second. The page is looked for up to 30 times a second (was 14), and the outline is drawn without redrawing the whole screen.
- Smoother letters in Document: the edge of each stroke is anti-aliased across one pixel, following its true outline, instead of a staircase. B&W stays strictly black and white.
- Page preview: pinch, double tap (or double click) and the mouse wheel zoom in; drag to look around. Zoomed in, the page is drawn at the size it is saved at.

Mac app
- Print (⌘P) works. The pages are drawn by the app and go to the system's print dialog. If that fails, the PDF opens in the system's viewer to print from there.

Fixes
- Rotated pages: text written upright on a turned page no longer comes apart one letter per line. This happened to scans made searchable and turned, and it broke selection, copying, highlights and the text view.
- Notes: deleting a note while editing another can no longer overwrite a third note's text.
- Text view: changing the text size, line spacing or font on a phone keeps your place.
- Dual pane:
  - A document open beside the list goes on as a full-screen reader when the window gets narrower, or after you save it in a narrow window. It no longer closes.
  - Keys typed in the search field (↓, ⌘K, ⌘N, ⌘O) work.
  - The selection bar no longer covers the search field.
  - Leaving with only typed details unsaved now says so.
- Changing the Tessel folder: if a move stops part way, the old folder stays the Tessel folder, and trying again moves the rest. An `inbox` folder in a different case is treated as the inbox. When you change to this device's own folder, the trash stays in the old folder.
- Inbox:
  - A new file with the same name no longer gets the old file's typed details.
  - Errors are written out in words, in your language.
  - A second Undo gets its own time.
- Old copies moved into a shared Tessel folder are no longer sent again when the folder already has them.
- A scan started while "Clean up pages" is still preparing waits for it, so no pages end up in the wrong scan.
- Clean up pages → Discard goes back to the document instead of opening a second copy of it.
- An AI address that redirects now says it redirects, on every platform.
- Rules: Add rule says what is missing. Save writes once.
- Importing a folder with nothing new says so.
