**Nothing typed gets lost.** Text being typed in a form field, and details not saved yet, count as unsaved: Back and closing ask first, and ⌘S saves them. A document under another one you opened keeps its edits and doesn't react to your keys.

**Revisions stay apart.** Opening a newer revision of a document (the same PDF with changes appended) makes its own entry, so saving one never writes over the other; the inbox checks “already in the archive” against the filed file itself. Signed PDFs are saved as an update, so their signatures stay valid.

**Reading on every device.** Of several entries of one document, the one changed last counts, so a position or bookmark set on one device is no longer undone by another. A document moved or filed on another device is followed, not opened twice.

**Offline after an update.** A new version caches everything it needs when it installs and takes over once the last one's tabs are closed, so the web app starts offline straight after an update.

**Faster and steadier.** Searching a long PDF no longer holds up drawing pages, saving or closing; typing a new search stops the old one at once. Renamed and moved files keep their place in the index and in Documents. The index looks again every few minutes while Tessel is open, so new scans and changes from your other devices show up. A long document's notes load without holding up its pages, the reader and lists redraw less, and thumbnails take less memory and storage.

**Better results.** Version numbers (“Version 2.1.19”) aren't read as dates, a name template drops a missing value with its separator, and files with a slightly misplaced cross-reference open. Documents that can't be opened here (password, damage) are listed and found by name. The inbox files nothing while its rules can't be read.

**AI reading.** Plain http is used only for addresses on this device or your network, so the key is never sent unencrypted. Messages say what went wrong (offline, unknown address, no answer, not an AI API, timed out). Handwriting is placed on the right page even when the model skips a blank one, long documents get room for their whole reply, and a model that doesn't answer within a few minutes leaves the scan with its own text.

**Scanner.** Write access to the folder is asked for when you tap Save, not after the PDF is made. The crop screen says why it opened, messages stay clear of the status line and the page's buttons, “Compare” no longer shares its name with the Original filter, and filters can't be tapped while nothing is selected.

**Wide windows.** The sidebar stays beside Inbox, Trash, Sync, Rules, Settings and folders, with the screen you're on lit, and every screen has the same column width.

**Easier to use.** The trash shows each document's title, the folder it came from and how many days it has left. Sync shows when a conflict happened in your time. Esc and Back end selecting, and switching between All and Folders does too. Renaming in Documents says it renames the file, not the title. Files that can't be added say so on any screen. Empty Documents' Add folder adds one straight away. The reader's side panels and the end of the text stay clear of the page and zoom buttons.

**Accessibility.** Switches, dialogs (password, note) and navigation are announced as what they are, Esc and Back close dialogs and focus returns where it was, buttons that repeat on a screen name their document, and the drop area is hidden from screen readers until something is dragged.

**German.** Headers, selection labels, dialogs and trash rows fit narrow phones (long words break at syllables), and several texts read more naturally.

**Android.** The app recovers when its WebView's process dies, keeps unsaved edits when the font size or language changes, and won't copy a folder into itself. Writing into a folder picked through the system tries beside the file first, moves and deletes report each item, and SD cards and USB drives open from All documents.

**Releases.** A version is published only once the web app's checks have passed on it.
