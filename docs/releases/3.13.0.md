**Types and tags stay consistent: the AI chooses from the ones in use, and a new screen tidies up the rest.**

Filling in details with AI (Angaben, the inbox, scans read with AI)
- The model is given the types and the most used tags already in your archive. It uses one of those where it fits, and makes up a new one only where none does.
- The type and the tags are in the app's language, whatever language the document is in, so an invoice is "Rechnung" whether it is written in German, French or English. The title stays in the document's own language.
- Its answer is matched onto your words in any case: "rechnungen", "Rechnungen" and a typo of "Versicherung" become the name you already use.
- At most three tags, each a topic. A tag no longer repeats the type, the sender or the year, which have fields of their own.
- In Details, a tag that isn't in use anywhere yet is marked "new", so a made-up one shows before you save.
- With no types in use yet, the model chooses from a short starter list (Rechnung, Quittung, Brief, Vertrag, Kontoauszug, …).

Tidy up tags (Documents → ⋯ → Tidy up tags)
- Three steps, each going further than the one before:
  - Spellings: the same word written differently becomes its most used spelling. This step needs no AI.
  - Same meaning: synonyms and translations ("Tax", "Steuer") become one name. This step uses AI.
  - Broader topics: tags become broader ones ("Zahnarzt", "Hausarzt" → "Gesundheit"). This step uses AI.
- Tags that only repeat a document's own type or sender can be removed in the same pass.
- Each proposed group shows its names with how many documents use them. Tap a name to leave it as it is, or type over the new name.
- Nothing is written until you choose "Change N documents". Then only the documents that change are rewritten.
