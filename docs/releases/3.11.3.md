**Selecting text stops where you let go, and the list keeps up.**

- **Selecting with the mouse:** letting go in the gutter between columns, or in the space below a paragraph, ends the selection on that line — it no longer runs through the rest of the column and into the next.
- **The highlight bubble** sits below the selection when dragging down and above it when dragging up, off the selected lines.
- **Documents:** opening a document beside the list no longer empties the list for a moment; a document kept in Tessel is listed at once.
- **Smaller things:** the Save, Discard and Cancel dialog fits on one row in German; the details' button says Save details; Rules says where it was reached from; on phones and tablets the document menu leaves out New window and key hints; the search palette's German hint fits on a phone.
