**Safer saving, and a round of fixes everywhere.**

- **A file changed elsewhere isn't silently overwritten.** When a PDF changed since you opened it (synced from another device, saved by another app), Saving asks before writing your version over it. Reading text in the background (Improve with AI, Make searchable) reads the file again if you saved notes meanwhile, instead of writing over them.
- **Undo and redo know what's saved.** Undoing to the saved state and then changing something else no longer shows the document as saved when it isn't.
- **Saving details with unsaved notes asks first**, since both go into the file.
- **Desktop:** the Notes tab of a docked Find panel lists notes again; the reader bar and the list header fall back to ⋯ when the pane is narrow; a document opened from Inbox or Duplicates no longer disappears into the hidden pane; narrowing the window keeps a document with unsaved changes open; keys no longer act on the list behind an open menu or sheet; quickly stepping through documents ends on the right one. Menus are in German on German Macs, update checks say when they failed, and "Open with" works with no window open.
- **Documents:** emptying a field in Details for several documents no longer clears it in all of them; dragging selected rows carries only those shown; tags aren't added twice in different case; files dropped on the window are read for text like files added.
- **Text view:** two-column scans are read column by column, not across; numbered items like "1. Marketing" and German wraps like "z. B." or "19. Jahrhundert" are no longer mistaken for lists or dates; a document with text on only some pages is no longer treated as having none; one unreadable page no longer stops text recognition; text read from old pages is forgotten after Clean up pages.
- **AI reading:** the reason a model failed (a wrong key, a busy server) is shown; page numbers counted from 0 no longer drop a page; models without structured output are told the answer's shape; the key is cleared when the address or API type changes, so it isn't sent to another service.
- **Phones:** with unsaved changes, Save is an icon and Undo/Redo move into ⋯, so the title and ⋯ stay in sight.
- **Android:** the AI key is no longer included in device backups; reopening Tessel from Recents doesn't open a shared file again.
- Signed PDFs no longer get a text layer unless you ask for one; light-theme captions, hints and switches have more contrast; clearer German wording.
