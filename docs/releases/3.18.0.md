**Default tags: twelve areas of life with descriptions, and rules that keep the AI from inventing overlapping ones.**

- **Default tags** (Settings → AI → Types and tags): Health, Insurance, Taxes, Finances, Work, Education, Home, Transport, Phone & Internet, Identity, Family, Legal (in German: Gesundheit, Versicherung, Steuern, Finanzen, Arbeit, Bildung, Wohnen, Mobilität, Telefon & Internet, Identität, Familie, Recht). Each has a description of what belongs in it. None contains another, and none is a type of document or a kind of sender. A list you already saved stays as it is.
- **Tag rules for the AI.** Every request that gives or proposes tags (suggested details, reading added documents, Analyse, Tidy up) now spells out what a tag is: one area of life the document is about. A tag is never a type of document, never a kind of sender (authorities, banks), never a date or a state, never two areas joined into one ("education and career"), never a kind of data ("personal data"). Tags don't overlap.
- **Tidy up → Tags** starts from the tags in Settings (ticked) whenever there are some. The model's own suggestion is used only when the list is empty. That suggestion follows the same rules, and a suggested tag that is one of the types or a company's name is dropped.
