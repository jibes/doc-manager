# Tessel name and logo

The code is free software ([AGPL-3.0-or-later](LICENSE)). The name **Tessel** and the Tessel mark (a page made of four tiles with one accent tile) identify the official project. This policy keeps that identity trustworthy: if something is called Tessel, people should be able to rely on it being the ad-free, account-free app built from this repository.

## You may, without asking

- Use the name to refer to the project, e.g. "works with Tessel" or "a fork of Tessel".
- Build and run unmodified official releases and call them Tessel.
- Use the name and mark in articles, reviews, tutorials and talks about the project.

## Please don't, without written permission

- Publish a modified version under the name Tessel or with the Tessel mark. **Forks are welcome under a different name and icon.**
- Distribute any version that adds ads, tracking, paywalls or account requirements under the Tessel name.
- Use the name or mark for a different product, or in a way that suggests endorsement.

Questions: open an issue in this repository.
